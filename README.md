# 🍃 Rithwik Foods - Premium Cold-Pressed Oils

A premium, high-performance web experience for **Rithwik Foods**, specializing in pure cold-pressed oils, spices, and organic seeds. Built with a focus on rich aesthetics, dynamic animations, and mobile-first responsiveness.

## 🚀 Live Demo
[https://rithwik-foods.vercel.app](https://rithwik-foods.vercel.app)

## ✨ Features
- **Modern Design**: Vibrant aesthetics with glassmorphism and custom brand gradients.
- **Dynamic Product Grid**: Collection page featuring live search and category filtering.
- **Responsive Layout**: Optimized for mobile and desktop with a focus on brand storytelling.
- **Direct Engagement**: Integrated WhatsApp floating action button for instant customer support.
- **Optimized Assets**: Custom-generated banners for "Pure Cold-Pressed Oils" and other categories.

## 🛠️ Tech Stack
- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS (Custom Token System)
- **Logic**: Vanilla JavaScript
- **Deployment**: GitHub + Vercel
- **Icons**: FontAwesome 6.0

## 📦 Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/Prophecccy/RithwikFoods.git
   ```
2. Open `index.html` in any modern browser.
3. No build step required—it's high-speed static code.
